# 双均线策略回测

## 策略逻辑
- 5日均线上穿20日均线 → 买入
- 5日均线下穿20日均线 → 卖出

## 使用方法

2. 在代码中填入你的 Tushare Token
3. 运行：`python dual_ma_strategy.py`
   ## 回测结果（2020-2026，贵州茅台）

| 指标 | 数值 | 分析 |
|---|---|---|
| 年化收益率 | 9.41% | 策略产生正收益，但波动剧烈 |
| 夏普比率 | -0.12 | 风险调整后收益低于无风险利率 |
| 最大回撤 | -67.04% | 趋势策略在长期下跌市场中面临巨大回撤 |
| 胜率 | 50.63% | 盈亏平衡附近，盈利依赖大趋势行情 |

**结论**：双均线策略在单边趋势中有效，但在震荡或反转行情中表现不佳。需要加入止损条件或结合其他过滤指标。

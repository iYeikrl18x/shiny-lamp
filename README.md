# 基于贵州茅台进行双均线回测延伸至多股票对比（贵州茅台、五粮液、宁德时代、万科A、中国平安）

## 项目亮点
- ✅ 完整回测流程：数据获取 → 信号生成 → 收益计算 → 风险指标
- ✅ 多股票对比：贵州茅台、五粮液、宁德时代、万科A、中国平安
- ✅ 风险指标：年化收益、夏普比率、最大回撤、胜率
- ✅ 代码规范：向量化计算、异常处理、模块化函数
- ✅ 可视化：累计收益曲线、买卖点标记、多股票对比图

## 策略简介
- 快线：5日简单移动均线  
- 慢线：20日简单移动均线  
- 交易规则：  
  - 金叉（5日线上穿20日线）→ 买入  
  - 死叉（5日线下穿20日线）→ 卖出  

## 回测设置
- 数据源：Tushare Pro  
- 回测区间：2020-01-01 至 2026-04-30  
- 初始资金：1（净值法）  
- 无风险利率：2%（年化）
  
## 回测结果（2020-2026，贵州茅台）

| 指标 | 数值 | 分析 |
|---|---|---|
| 年化收益率 | -5.09% | 茅台趋势策略在下跌时中必然亏损 |
| 夏普比率 | -0.12 | 风险调整后收益低于无风险利率 |
| 最大回撤 | -67.04% | 趋势策略在长期下跌市场中面临巨大回撤 |
| 胜率 | 50.63% | 盈亏平衡附近，盈利依赖大趋势行情 |

**结论**：双均线策略在2020-2026年茅台中取得负收益（年化-5.09%，夏普-0.12，最大回撤-67%），主要亏损来自2021年后的震荡下跌阶段。尽管策略在2020年单边上涨中表现良好，但缺乏止损机制和行情过滤导致回撤失控。

## 多股票绩效汇总（5日/20日双均线）

| 股票     | 年化收益 | 夏普比率 | 最大回撤 | 胜率   |
|----------|----------|----------|----------|--------|
| 贵州茅台 | -5.09%   | -0.12    | -67.04%  | 50.63% |
| 五粮液   | 4.86%    | 0.25     | -48.23%  | 52.43% |
| 宁德时代 | -17.44%  | -0.19    | -82.08%  | 48.21% |
| 万科A    | 4.03%    | 0.24     | -46.10%  | 51.63% |
| 中国平安 | -5.63%   | -0.15    | -60.08%  | 48.30% |

> 注：以上为回测结果，不代表未来收益。

## 结果解读
- 五粮液、万科A在回测期内获得正的年化收益，夏普比率略高于0.2，但最大回撤仍较大。
- 宁德时代等成长股在2021年后经历大幅回调，趋势策略遭遇严重回撤。
- 双均线策略在单边上涨行情中表现较好，但在震荡或下跌市中容易亏损。

## 局限性
- 双均线策略在震荡市中频繁止损，导致较大回撤（如宁德时代最大回撤-82%）
- 未考虑交易成本（滑点、佣金）
- 未加入风险管理（止损、仓位控制）

## 未来改进方向
- 加入波动率过滤（如 ADX、布林带宽度）减少震荡市交易
- 引入凯利公式进行动态仓位管理
- 扩展至更多股票或指数成分股
